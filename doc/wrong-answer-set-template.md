# 真实错题集标注模板

> **用途**：诊断质量验证的基准数据（交接清单 §8：真实学生的错误无法生成，模型造的数据验证模型等于自己证明自己）。
> **谁填**：只能人填。学生作答应来自真实作业/试卷（拍照转写即可），不要让任何 AI 代写"典型错误"。
> **填多少**：3~5 道即可起步（先冒烟）；10~20 道才有统计意义（验收口径）。宁少而真，不多而假。
> **隐私**：填好后放本地（勿提交进仓库，建议加入 `.gitignore` 的路径如 `doc/local/`），外发前脱敏姓名。

## 一、填写格式

每题一条记录，五栏缺一不可（"期望错因"由了解学生情况的人标注）：

| # | 字段 | 说明 | 示例 |
|---|---|---|---|
| 1 | `题目` | 原题完整题干（含条件与问句），长题可附截图路径 | 已知关于 x 的方程 x²−2(m−1)x+m²=0，若方程有两个不等实根，求 m 的取值范围 |
| 2 | `学生作答` | 学生原始作答，**逐字转写，不要修正式我**（改写会破坏 guard 与归因验证） | 解：Δ=(m−1)²−m²>0，所以 m>−1/2，答：m>−1/2 |
| 3 | `正确答案` | 标准答案（可含解析要点） | Δ=4(m−1)²−4m²=−8m+4>0 → m<1/2 |
| 4 | `期望错因` | 1 主 +至多 1 次，用错因 code（对照表见下）， unsure 就写 `unsure` | 主 `boundary_error`；次 `formula_misuse` |
| 5 | `判定说明` | 一句话说明你为何这样标（学生实际怎么错的） | 展开时 (m−1)²−m² 算成 m²−2m+1−m²，移项后不等号方向没反转 |

示例行（可直接复制）：

```
Q1 | 已知关于x的方程x²−2(m−1)x+m²=0有两个不等实根，求m的取值范围 | 解：Δ=(m−1)²−m²>0，所以m>−1/2 | m<1/2 | boundary_error + formula_misuse | 移项后不等号方向未反转；展开也有抄写错
```

## 二、错因 code 对照表（lib/diagnose/error-causes.ts 同源）

| code | 标签 | code | 标签 |
|---|---|---|---|
| `misread` | 审题不清 | `case_miss` | 分类讨论遗漏 |
| `pure_guess` | 纯粹选错 | `step_jump` | 步骤断层 |
| `calc_error` | 计算失误 | `modeling_error` | 转化/建模错误 |
| `transcribe` | 抄写错误 | `boundary_error` | 边界处理错误 |
| `concept_confuse` | 概念混淆 | `graph_misread` | 图象误判 |
| `formula_misuse` | 公式误用 | `unit_error` | 单位/量纲错误 |
| `hidden_cond` | 隐含条件遗漏 | `answer_off_target` | 答非所问 |

标注不了就写 `unsure`——不确定的样本比强行标注的样本更有价值（后者会污染评估）。

## 三、使用口径（验证时怎么算通过）

每道题跑一次完整诊断，对照三件事：

1. **错因命中**：主错因 code 与期望一致（或判定说明能解释的近义错因）记 1 分；次错因不强制。
2. **诊断≠解析**（硬判据）：输出必须引用学生作答原文片段；出现"讲一遍正确解法再补一句你错了"即记违规，无论错因对不对。
3. **阶梯与预算**：补问 ≤2 轮、默认停在提示 L1、策略卡步骤与错因对应。

三件事分开记录，**第 2 条一票否决**（它是产品与搜题工具的分界线）。

## 四、挂账说明

- 本模板只解决"数据怎么填"；数据齐 3 道后的人工评审流程由人另行组织（演示脚本编排也是人的活，见交接清单 §8）。
- `unsure` 样本积累多了可以反向校准错因表条目（D 级：实测后错因枚举可增删，不必回头改文档）。
